## v0.1 — Playable toy (placeholder art/sound)
**Goal:** A person on a phone or laptop can feed the rabbit and pet it, and the
rabbit animates and makes cute noises — all with deliberately temporary
placeholder sprites and synthesized sounds.
**Dependencies:** v0 milestone met (Q-003 resolved ✅ · 2026-10-23).
**Status:** 🟡 Code-complete & machine-verified (2026-10-23); scripted browser suite still pending (see HANDOFF).
**Milestone criteria** (ship when all are ✅):
- [x] Pet gesture (pointer stroke on rabbit) triggers happy/wiggle animation.
- [x] Feed affordance (drag or tap carrot) triggers eating animation + fed counter.
- [x] At least two distinct cute noises (munch, chirrup; + soft blip) via WebAudio; mute toggle persists.
- [x] Idle loop with breathing + occasional blink + ear twitch.
- [x] Input via unified Pointer Events, single code path (mouse machine-verified; touch same API surface).
- [x] Core modules exercised by light unit tests (13 `node --test` checks in `tests/`; Q-008 resolution (C) unit half).
- [ ] Scripted Playwright smoke suite lands before v1 (dev-dep, not runtime — see HANDOFF next steps).
**Verification record (2026-10-23, playwright session):** stroke→`happy` FSM assertion, feed→counter+localStorage, mute toggle↔persist both directions, zero JS console errors (favicon 404 only).
**Out of scope:** any pipeline-generated (final) art; name input; reduced-motion polish beyond basic honoring (flag checked in renderer).

## What Determines Version Boundaries
v0 = the repo is trustworthy (runs + documented). v0.1 = the toy is honestly
fun/working with placeholders. v0.2 = the aesthetic becomes product-grade via
the tracked pipeline. v1 = a stranger with a phone link can enjoy it. v2 =
affection depth features without expanding scope creep. Any feature that adds
network calls, accounts, or game mechanics (hunger/auth/game loops) is rejected
from all versions by the PRD Non-Goals unless the PRD itself is amended.
