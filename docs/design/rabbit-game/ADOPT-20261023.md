## Feel rule (from game-feel.md, distilled)

1. Input → visible response ≤ ~100 ms (fix first; juice can't hide lag).
2. Response curves over hard lines (ease-out / slight overshoot on player-driven motion).
3. Contact feedback at the moment of the act (flash/squash stop — here: chomp, ear wiggle, pop).
4. Audio-visual same-frame sync, with variance across repeats.
5. Readability: feedback clarifies state; anything that hides the rabbit or the next affordance is a bug, not polish.

## Rabbit visual scorecard (adapted from the AAA 10-category card)

Graded 1–3 with their anchor logic; **v1-ready bar: nothing below 2.**
Their materials/lighting/VFX-3D/performance categories don't map to a flat 2D
toy (performance folds into the scripted suite once it exists).

| Category | 1 | 2 | 3 |
| -------- | - | - | - |
| Art direction | bands/labels, default look | style-locked pastel kawaii through all surfaces | every visible surface authored in canon style |
| Hero | generic sprite anywhere | canon sprite, correct per-env placement | expressive states + expression-sheet depth |
| Feed affordance | hidden or ambiguous control | visible basket with readable affordance | choreographed: ghost-follow, snap-to-mouth, crumbs-worthy feedback |
| Environment | placeholder bands | two settings with placement rules | settings aid mood; props feel alive to the pet |
| Motion | idle loop only | event-driven eat/pet/hop + ghost drag | all events juicy AND readable (Feel rule) |
| UI/HUD | unstyled text | styled chips, aria states, counters | responsive + touch + focus states + safe areas |

## Rejected (with reasons)

- **Vite/TypeScript/npm scaffold, Three.js renderer, post-processing, lil-gui,
  physics engines** — AGENTS.md rule 1 (no frameworks, no build step). No
  exception asked for, none needed.
- **Tripo / ElevenLabs external asset lanes** — rule 4 (paid clouds need explicit
  per-session authorization; WebAudio synth covers this toy's noises; no need arises).
- **npm visual-regression harness (pixelmatch-style deps)** — runtime/deps rule;
  our pixel-verified art critiques + browser smoke cover today's needs. Revisit
  only if art starts changing every commit.
- **Their bot-playtest TS template** — replaced by a single Playwright-driven
  script when the scripted suite lands (dev-dep only).
