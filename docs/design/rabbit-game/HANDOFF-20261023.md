## Context Summary

The user wants a tiny pure-HTML browser toy: a virtual rabbit you can feed
carrots and pet; the rabbit responds with small animations and cute noises.
The repo (`rabbit-game`, currently containing only this design folder) will
become a public GitHub repo once the basics exist — this is its founding design.

A sibling repo, `space-adventure-prototype`, already proved an agentic
game-production pipeline: system-forge design docs under `docs/design/`, a
SHOTKIT brand-extraction phase (input brief → brand-lock → hash-locked
generation rounds), and a hybrid ComfyUI art pipeline (comfy-cli + comfy-mcp via
LeanCTX) with immutable generation rounds, pixel-verified critiques, and
acceptance-provenance discipline. This design intentionally reuses those
conventions rather than inventing new ones — the runtime is different (pure web
instead of Godot), the discipline is identical.

## Notes for the Next Agent or Human
- The sibling repo `space-adventure-prototype` remains the authoritative example of
  the conventions this design adapts — check its docs before inventing structure.
- Art pipeline machinery (ComfyUI install, comfy-cli, comfy-mcp) already exists
  on this machine outside TCC-protected folders (`~/AI/comfy/ComfyUI`) — see
  precursor `art/ART-SETUP.md`. Reuse it; do not reinstall.
- Browser gotchas handled: audio requires first gesture (unlock hook wired to
  every input path); the favicon links to `assets/character/rabbit-idle.png`
  (the v0.1-era 404 is cured).
- Chrome caches index.html + ES modules aggressively — after head edits, hard
  reload (or CDP `Network.clearBrowserCache`) or you get stale-script crashes
  (e.g. `#carrot` renamed to `#basket` + old main.js = boot TypeError).
- `globalThis.__rabbit_game` is a deliberate debug/verification hook in
  `scripts/main.js` — browser smoke asserts read FSM state through it. Keep it.
- **`main` is production (2026-10-25)**: pushing auto-deploys
  rabbit.brainvault.xyz within ~1 min (Cloudflare Workers Git integration;
  `wrangler.jsonc` + `.assetsignore` define the deploy). Verify locally
  (dev server + `npm test`) before pushing; broken main = broken live site.
- **`import/` holds the user's arrived audio clips** (gitignored, local-only
  per Q-018 — never commit or deploy).
- Pure-HTML means the shipped artifact is the source tree; mind diff hygiene
  (small files, no minification, no bundling).
- Placeholder-art rule reminder: the code-drawn rabbit is clearly labeled on
  screen and must be replaced in v0.2; it may never reach v1.
